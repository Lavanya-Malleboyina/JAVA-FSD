Arrow function:
    it is used to reduce the syntax  
    it is introduced in the version es6
    it follows 3 rules:
        1.if arrow function contains more than one statement we keep in braces{}
        2.if arrow function contains return keyword then also we need keep in braces{}
        3.in arrow functions this keyword works differently(so if you are accessing this keyword in arrow function it will target windows object)
Nested functions:
    function having another function.
High OrderFunction:
    Any function that accept another function as a parameter
callback Function:
    any functions that will pass as parameter to the high order function that function we called as a callback functions.
Generator Function:
    it used to generate a new variable.
    we use the yield keyword in this function.
    it used when you dont know how
    syntax:
        function* generateFun(){
            yield a=10;
            yield b=20;
            console.log("This is generate function");
        }
